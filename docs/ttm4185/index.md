# TTM4185 Sikkerhet og robusthet i IKT-systemer

Emnet handler om hvordan IKT-systemer kan beskyttes mot både angrep og vanlige feil, og om hvordan man vurderer risikoen for at noe går galt. Faglærer er professor Poul Einar Heegaard (NTNU IIK), med bidrag fra Karin Bernsmed (SINTEF Digital).

!!! abstract "Kjernen i emnet på én linje"
    Et sikkert og robust system tåler både **angrep** (tilsiktet), **menneskelige feil** (utilsiktet) og **tilfeldige feil** (vær, maskinvare, programvare), og man må se på alle tre samtidig.

# Begreper

Pensum blander norsk og engelsk. Her er begrepene side om side, slik at søket finner dem på begge språk.

## Sikkerhet og personvern

Confidentiality · konfidensialitet
:   Bare autoriserte får tilgang til informasjonen.

Integrity · integritet
:   Informasjonen er beskyttet mot uautorisert endring eller sletting.

Availability · tilgjengelighet
:   Beskyttet mot uautorisert avbrudd (security), eller sannsynligheten for at tjenesten leveres (dependability).

Authenticity · autentisitet
:   Vi kan bekrefte hvem som sendte en melding.

Non-repudiation · ikke-benekting
:   Ingen kan nekte for å ha sendt eller mottatt.

Accountability · sporbarhet
:   Handlinger kan spores entydig til den som gjorde dem.

Personal data · personopplysninger
:   All informasjon som kan knyttes til en identifiserbar person.

Data subject · den registrerte
:   Personen opplysningene gjelder.

Data controller · behandlingsansvarlig
:   Bestemmer formål og midler for behandlingen.

Data processor · databehandler
:   Behandler opplysninger på vegne av den behandlingsansvarlige.

## Pålitelighet og safety

Dependability · pålitelighet (samlebegrep)
:   Tjenesten kan med rette stoles på.

Reliability · pålitelighet (avbruddsfrihet)
:   Leverer tjenesten uten avbrudd i et tidsintervall.

Maintainability · vedlikeholdbarhet
:   Hvor lett systemet kan gjenopprettes etter feil.

Fault · feilårsak
:   Defekt i systemet som kan føre til en error.

Error · feiltilstand
:   Del av systemtilstanden som kan føre til failure.

Failure · feilytring
:   Tjenesten avviker fra spesifikasjonen.

Fault tolerance · feiltoleranse
:   Systemet leverer tjenesten selv om en fault inntreffer, typisk med redundans.

Safety · sikkerhet (for liv, helse og miljø)
:   Beskyttelse mot utilsiktede hendelser med katastrofale følger.

Fail-safe
:   Systemet går til en trygg tilstand når noe feiler.

Single point of failure
:   Én komponent som tar ned hele tjenesten hvis den feiler.

## Ytelse

Capacity · kapasitet
:   Maks last systemet kan håndtere per tidsenhet.

Throughput · gjennomstrømning
:   Andelen av kapasiteten brukerne faktisk bruker.

Delay · forsinkelse
:   Tiden det tar å fullføre tjenesten.

## Risiko

Asset · verdi / eiendel
:   Noe av verdi som må beskyttes.

Threat · trussel
:   Mulig årsak til en uønsket hendelse.

Vulnerability · sårbarhet
:   Svakhet som lar en trussel føre til en hendelse.

Incident / unwanted event · uønsket hendelse
:   Noe som skader eller reduserer verdien av en verdi.

Likelihood · sannsynlighet / trolighet
:   Hvor trolig det er at hendelsen inntreffer.

Consequence · konsekvens
:   Virkningen av hendelsen på verdien.

Risk treatment · risikohåndtering
:   Redusere, overføre, akseptere eller unngå.

SLA · tjenestenivåavtale
:   Avtale mellom bruker og tilbyder om tjenestens kvalitet.

DPA · databehandleravtale
:   Avtale som regulerer behandling av personopplysninger ved tjenesteutsetting.

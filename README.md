# Studiebasen

Mine studienotater som en lokal nettside, bygget med [MkDocs](https://www.mkdocs.org/) og temaet [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/).

## Kom i gang
Clone repoet, og så kjører du start.bat filen. Dette kan gjøres gjennom terminalen ved å skrive .\start.bat, eller å dobbelklikke filen i filutforskeren.
